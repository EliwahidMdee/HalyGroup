# Haly Group Limited — Under Construction

Static landing page for GitHub Pages.

## Deploy
1. Push this folder to a GitHub repo.
2. Go to Settings → Pages.
3. Set Source to `Deploy from a branch`, Branch `main` (or `master`), Folder `/ (root)`.
4. Your site will be published at `https://<username>.github.io/<repo>/` or custom domain.

## Files
- `index.html`
- `style.css`
- `app.js`
- `favicon.png`, `icon-192.png` (placeholders)
- `.nojekyll` (prevents Jekyll processing)

## Custom domain
Add a `CNAME` file with your domain (e.g. `halygroupltd.com`) if using a custom domain.
